# Web de usuario

`experience.tsx` contiene la interfaz pública: nombre, solicitud de acceso, espera de aprobación, selección de artista, selfie, generación y descarga.

La entrada de Next.js es `../app/page.tsx`; la URL es `/`.

Ejecuta `npm run dev` desde la raíz WEB, donde está package.json. Esta carpeta es parte de la aplicación compartida. El visitante no puede subir fotos de artistas ni acceder a funciones administrativas.
